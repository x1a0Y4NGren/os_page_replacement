# 页面置换算法说明

负责人：B

本文档用于记录 OPT、FIFO、LRU 三种页面置换算法的原理、实现方式、优缺点和实验性能分析。

## 统一接口

```c
double run_opt(const int pages[], int n, int frame_count);
double run_fifo(const int pages[], int n, int frame_count);
double run_lru(const int pages[], int n, int frame_count);
```

返回值为命中率：

```text
hit_rate = hit_count / total_access_count
```

## OPT

OPT 算法在发生缺页且内存已满时，淘汰未来最长时间不再访问的页面。如果某个页面之后不再访问，则优先淘汰该页面。

优点：

- 理论命中率最高，可作为其他算法的性能上限。
- 适合用于实验对比和评价 FIFO、LRU 的差距。

缺点：

- 实际系统无法提前知道完整的未来访问序列，因此不能直接用于真实操作系统。
- 每次缺页都需要向后扫描页地址流，模拟成本较高。

## FIFO

FIFO 算法在发生缺页且内存已满时，淘汰最早进入内存的页面。

优点：

- 实现简单，只需要维护进入内存的先后顺序。
- 运行开销低。

缺点：

- 不考虑页面最近是否被频繁访问。
- 可能淘汰仍然常用的页面，存在 Belady 异常风险。

## LRU

LRU 算法在发生缺页且内存已满时，淘汰最长时间未被访问的页面。

优点：

- 利用程序局部性原理，通常比 FIFO 更稳定。
- 不需要提前知道未来访问序列，实际系统可用近似算法实现。

缺点：

- 需要维护最近访问时间或访问顺序。
- 精确 LRU 在真实系统中维护成本较高。
