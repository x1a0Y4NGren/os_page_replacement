## 指令序列生成

实验共生成 320 条指令，指令地址范围为 `[0, 319]`。

默认实验采用 50% 顺序执行比例，符合实验报告书中的基本要求。扩展对比实验支持 25% 和 75% 顺序执行比例，用于观察程序局部性变化对命中率的影响。

当前实现入口：

```c
void generate_instruction_sequence(int instructions[], int n, double sequential_ratio);
```

## 页地址流转换

虚存容量为 32 页，每页存放 10 条指令：

```text
page = instruction / 10
```

例如：

- 指令 0 到 9 属于第 0 页。
- 指令 10 到 19 属于第 1 页。
- 指令 310 到 319 属于第 31 页。

当前实现入口：

```c
void convert_to_page_stream(const int instructions[], int pages[], int n);
```

## 初步结论预留

TODO(Member C):

- 页框数增加时，三种算法命中率一般上升。
- OPT 通常作为理论最优上界。
- 顺序执行比例越高，局部性越强，LRU 和 FIFO 的命中率通常会提高。
- 随机性较强时，算法之间差距可能更明显。
