## 科技伦理思考

页面置换算法看似只是底层系统策略，但在 Web 服务器、云平台和多租户环境中会影响用户体验和资源分配公平性。

可讨论方向：

- 公平性：内存资源紧张时，算法是否会长期偏向某类访问模式或某些用户请求。
- 透明性：系统优化策略是否应在服务等级协议或技术文档中说明。
- 稳定性：追求平均性能时，是否可能牺牲尾延迟用户的体验。
- 能耗：更高命中率可以减少磁盘或交换访问，有助于降低能耗。
- 开源责任：发布实验代码到 GitHub 或 Gitee 时，应保证代码说明清晰，避免误导他人将教学模拟结果直接当作生产结论。
